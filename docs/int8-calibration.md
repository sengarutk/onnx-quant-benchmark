# FP16 Conversion & Static INT8 PTQ Report

Generated by `scripts/quantize_and_validate.py`. Quality is measured with ONNX Runtime (CPU) on the full synthetic test split and compared with the PyTorch FP32 baseline (`results/baselines/`).

## 1. Settings

- **INT8**: ONNX Runtime `quantize_static`, QDQ format, calibration method selected per model on the calibration split among MinMax, Percentile, Entropy (detector: calibration-split mAP@50; autoencoder: anomaly-map relative error vs FP32), per-channel QInt8 weights, QUInt8 activations (symmetric), quantized op types: Conv, ConvTranspose, MatMul, Gemm.
- **FP16**: `onnxconverter_common.float16.convert_float_to_float16` with FP32 graph inputs/outputs.
- **Calibration data**: the labeled calibration split (`data/calibration/`, 100 detection / 100 normal industrial images), generated from a seed range disjoint from the test split (SHA-256 overlap verified to be 0).
