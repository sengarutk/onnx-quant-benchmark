# Data

All data is procedurally generated by `src/data/synthetic.py` (nothing is downloaded) and is git-ignored.

```
data/
├── sample_images/   # TEST split  - scripts/prepare_sample_data.py   (200 detection, 100 normal + 100 anomalous textures)
└── calibration/     # CALIBRATION split - scripts/prepare_calibration_data.py (100 labeled detection, 100 normal textures)
```

The TRAIN and VALIDATION splits are generated on the fly by `scripts/train_models.py`. Splits use disjoint seed
ranges, and the calibration script verifies zero SHA-256 overlap with the test split.
Detection labels are YOLO-format text files (`class cx cy w h`, normalized); `manifest.json` also stores pixel boxes.
